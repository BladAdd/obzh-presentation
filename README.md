# Правила поведения в опасных ситуациях — ОБЗР

Интерактивная презентация для урока ОБЗР (Основы безопасности жизнедеятельности).
Россия и Оренбургская область.

**Живая версия:** https://obzh-presentation.vercel.app

## Слайды (15)

1. **Титульный** — Правила поведения в опасных ситуациях
2. **Что такое ЧС** — Классификация чрезвычайных ситуаций
3. **Природные ЧС** — Наводнения, пожары, ураганы, морозы
4. **Техногенные ЧС** — Химические аварии, транспорт, энергетика
5. **Пожарная безопасность** — Правила при пожаре
6. **Эвакуация при ЧС** — План, документы, помощь другим
7. **Защита органов дыхания** — Противогаз, респиратор, ватно-марлевая повязка
8. **Землетрясение** — Действия до, во время и после
9. **Социальные угрозы и терроризм** — Бдительность и экстремизм
10. **Безопасность на воде и в быту**
11. **Первая медицинская помощь**
12. **Радиационная безопасность**
13. **Психологическая первая помощь**
14. **Особенности Оренбургской области**
15. **Итоги и автор**

## Технологии

- HTML5, CSS3, JavaScript — без сборки и фреймворков
- Three.js — деликатный фон из частиц
- Тематические SVG-иллюстрации (каска МЧС, огнетушитель, карта Оренбургской области)
- Адаптивная вёрстка под ноутбуки и проекторы

## Управление

- `←` `→` / `Space` — навигация по слайдам
- `Home` / `End` — первый / последний слайд
- `F` — полноэкранный режим
- Свайпы на мобильных устройствах
- Клик по точкам в нижней панели

## Режим без анимаций

Добавьте к адресу `?static`, например:

`https://obzh-presentation.vercel.app/?static#slide-7`

Отключает анимации и 3D-фон — удобно для скриншотов и печати в PDF.
Прямые ссылки на слайды: `#slide-1` … `#slide-15`.
